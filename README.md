# Die Stasie Hartenbos — Restaurant Landing Page

A single-page restaurant website for **Die Stasie**, a railway-themed restaurant and bar located in Hartenbos, South Africa.

## Tech Stack

- **Framework**: TanStack Start (React 19 + TanStack Router)
- **Styling**: Tailwind CSS v4 with custom CSS properties
- **Fonts**: Bebas Neue (display), Playfair Display (headings), Lato (body) — via Google Fonts
- **Build**: Vite
- **Hosting**: Netlify

## Running Locally

```bash
npm install
npm run dev
```

Opens at `http://localhost:3000`.

## Sections

- **Hero** — Full-viewport photo with animated entry and brand headline
- **About Us** — Story, atmosphere description, and key stats
- **Specials** — Weekly specials grid (Mon–Sun + Happy Hour)
- **Menu** — Tabbed menu: Starters, Mains, Pizza, Drinks
- **Trading Hours** — Day-by-day table with kitchen hours note
- **Gallery** — Asymmetric photo grid from the venue
- **Contact** — Address, phone, email, map embed, social links
